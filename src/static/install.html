Installing SimTX

All packages are served by manifest.simtx.net and signed with the SimTX package-signing key (SimTX Package Signing <packages@simtx.net>, fingerprint 18DDFED1FFF7FE5B0BFB20EDBF9413DA974E8B09). Always verify the fingerprint when trusting the key. If it does not match, stop and ask — do not install.

Ubuntu / Debian (24.04+, Debian 13+)

# 1. Trust the key
curl -fsSL https://manifest.simtx.net/pubkey | sudo gpg --dearmor -o /usr/share/keyrings/simtx-archive-keyring.gpg
gpg --show-keys /usr/share/keyrings/simtx-archive-keyring.gpg  # check the fingerprint above

# 2. Add the repo
sudo tee /etc/apt/sources.list.d/simtx.sources > /dev/null <<'EOF'
Types: deb
URIs: https://manifest.simtx.net
Suites: stable
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/simtx-archive-keyring.gpg
EOF

# 3. Install / update
sudo apt-get update
sudo apt-get install simtx

Verify: dpkg -s simtx | grep -E '^(Version|Status)' and simtx-cli version.

Arch Linux

# 1. Trust the key
curl -fsSL -O https://manifest.simtx.net/pubkey
mv pubkey simtx-signing-pubkey.asc
sudo pacman-key --add simtx-signing-pubkey.asc
sudo pacman-key --lsign-key 18DDFED1FFF7FE5B0BFB20EDBF9413DA974E8B09

# 2. Add the repo (above [core] in /etc/pacman.conf for priority)
printf '[simtx]\nServer = https://manifest.simtx.net/arch/$arch\nSigLevel = PackageRequired DatabaseOptional\n' | sudo tee -a /etc/pacman.conf > /dev/null

# 3. Install / update
sudo pacman -Sy simtx

Direct-URL install works too (pacman fetches the .sig itself): 

sudo pacman -U https://manifest.simtx.net/latest/app/linux/amd64/pkg.zst

Verify: pacman -Q simtx and simtx-cli version.

Fedora

# /etc/yum.repos.d/simtx.repo
[simtx]
name=simtx ($basearch)
baseurl=https://manifest.simtx.net/rpmrepo/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://manifest.simtx.net/pubkey
sudo dnf install simtx

Verify: rpm -q simtx and simtx-cli version.

AppImage (any distro)

curl -fsSL -O https://manifest.simtx.net/latest/app/linux/amd64/appimage
chmod +x simtx-*.AppImage
./simtx-*.AppImage

Check integrity first (hash published next to the image): 

curl -fsSL https://manifest.simtx.net/latest/app/linux/amd64/appimage-sha256
sha256sum simtx-*.AppImage

Installed AppImages self-update via the embedded channel (appimageupdatetool).

Headless CLI only

The simtx-cli binary ships inside every Linux package (/usr/bin/simtx-cli) and bundled in the AppImage. Standalone download: 

curl -fsSL -O https://manifest.simtx.net/latest/cli/linux/amd64/binary
chmod +x simtx-cli
./simtx-cli version

Troubleshooting

  • apt-get update: signature errors → re-check step 1 (keyring path in .sources must match where you wrote the .gpg file).
  • Arch SigLevel errors → re-run the pacman-key steps; the key must show as locally signed (pacman-key --list-sigs packages@simtx.net).
  • Fedora repomd.xml GPG signature verification error on first run → answer y to the key-import prompt (or pre-import with rpm --import), then retry.
  • Old Ubuntu (22.04) / Debian 12: unsupported — the GTK4 + WebKitGTK 6.0 stack needs Ubuntu 24.04+ / Debian 13+.
