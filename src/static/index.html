Headless CLI — simtx-cli

The headless transmitter (simtx-cli / simtx-cli.exe) ships bundled inside the installers above and as a standalone download below.

Download CLI
Native packages install the CLI to /usr/local/bin/simtx-cli. The AppImage carries it at usr/bin/simtx-cli (via --appimage-mount / --appimage-extract); the NSIS installer drops simtx-cli.exe next to the GUI exe.
curl -L -o simtx-cli /latest/cli/linux/amd64/binary
chmod +x simtx-cli
./simtx-cli --help
